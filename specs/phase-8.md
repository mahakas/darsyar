# Phase 8: Future Learning Tools (Deferred)

**Status:** Deferred; outside MVP  
**Dependencies:** New ADR and explicit owner approval

## Goal

Reserve a future design slot for quiz/question generation and learning profiles without accidentally expanding MVP.

## In scope

- [ ] Documentation/planning only until a new ADR is accepted.
- [ ] No endpoint, database implementation or UI action may be added under this phase now.

## Out of scope

- Automatic learning profile, quiz/test generator, bespoke academic counseling

## Acceptance criteria

- [ ] The default implementation is no implementation.
- [ ] Any activation starts with new accepted ADR and revised roadmap/spec.

## Required evidence

- Commands actually executed, exit code and important output.
- Files changed and references to applicable `R-NNN` rules.
- Risks, assumptions, and `NOT RUN` checks with exact blocker.
- New decisions in an ADR before code when required.
