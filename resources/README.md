# منابع آموزشی محلی

این ZIP ساختار پوشه‌ای خالی برای موضوع‌های مجاز و پایه‌های ۱ تا ۱۲ دارد؛ **هیچ کتاب یا متن درسی داخل بسته نیست** و وجود یک پوشه به معنی وجود یا اعتبار یک درس در آن پایه نیست. فایل واقعی فقط در صورت داشتن مجوز قانونی برای دریافت، ذخیره، OCR، embedding و نمایش اضافه شود.

مسیر استاندارد نسخهٔ ۴: `resources/<subject>/grade<grade>/<file>`. سال چاپ (`edition_year`) در manifest/metadata فایل نگهداری می‌شود، نه در یک پوشهٔ اجباری جداگانه. همچنین manifest صریح با schema معتبر، جایگزین قابل‌قبول مسیر پوشه است.

هر منبع باید حداقل عنوان، ناشر/مالک، سال چاپ، پایه، درس، نوع محتوا، hash، وضعیت مجوز و منشأ داشته باشد. اگر فرادادهٔ لازم مبهم است، ingestion باید fail-closed شود یا به بررسی انسانی برود؛ هیچ نگاشتی با حدس انجام نمی‌شود. محتوا و فایل‌های واقعی منابع را در Git commit نکن.
