# نگاشت پایهٔ آموزشی

| دستهٔ مسیر | پایهٔ canonical | وضعیت |
|---|---:|---|
| `grade1` … `grade6` | ۱ … ۶ | نظام جاری؛ metadata بررسی شود |
| `grade7` … `grade9` | ۷ … ۹ | نظام جاری؛ metadata بررسی شود |
| `grade10` … `grade12` | ۱۰ … ۱۲ | نظام جاری؛ metadata بررسی شود |
| `pre_university` / `grade_pre` | نگاشت خودکار ممنوع؛ نیازمند بازبینی سطح-منبع و تأیید صریح مالک | نظام قدیم؛ ADR-037 accepted (2026-11-09) |

طبق ADR-037 (accepted)، هیچ نگاشت خودکار/سراسری برای محتوای legacy وجود ندارد. هر منبع `pre_university`/`grade_pre` فقط پس از بازبینی صریح سطح-منبع و نگاشت پایهٔ تأییدشده توسط مالک می‌تواند به پایهٔ canonical نگاشت شود؛ منابع بازبینی‌نشده/مبهم → `needs_review` یا شکست ingestion. هم‌ارزی محتوایی/نظام آموزشی از نام پوشه استنتاج نمی‌شود. (OQ-009 بسته شد.)

`selected_grade` برای هر درخواست الزامی است؛ هر دو شاخهٔ dense و lexical باید `chunk.grade_level <= selected_grade` را در SQL اعمال کنند.
