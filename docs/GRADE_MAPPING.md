# نگاشت پایهٔ آموزشی

| دستهٔ مسیر | پایهٔ canonical | وضعیت |
|---|---:|---|
| `grade1` … `grade6` | ۱ … ۶ | نظام جاری؛ metadata بررسی شود |
| `grade7` … `grade9` | ۷ … ۹ | نظام جاری؛ metadata بررسی شود |
| `grade10` … `grade12` | ۱۰ … ۱۲ | نظام جاری؛ metadata بررسی شود |
| `pre_university` / `grade_pre` | نگاشت خودکار ممنوع در بستهٔ شروع | نظام قدیم؛ نیازمند بررسی و manifest صریح |

قاعدهٔ v4 برای محتوای قدیمی عبارت `pre_university → 12` را ذکر می‌کند، اما این نگاشت می‌تواند منابع تاریخی را به پایهٔ نامتناسب وصل کند. این بسته برای جلوگیری از تخصیص خاموش، نگاشت legacy را در ingestion واقعی تا دریافت تأیید مالک/ADR به review می‌فرستد. این مورد در `docs/OPEN_QUESTIONS.md` ثبت شده و قبل از فاز ۴ باید تعیین تکلیف شود.

`selected_grade` برای هر درخواست الزامی است؛ هر دو شاخهٔ dense و lexical باید `chunk.grade_level <= selected_grade` را در SQL اعمال کنند.
