# رجیستری مجوز منابع

هیچ کتاب/فایل آموزشی در این ZIP موجود نیست. پیش از ingestion هر منبع، manifest باید `license_note` و منشأ را داشته باشد و شرایط دریافت، OCR، embedding، ذخیره، نمایش و نقل‌قول بررسی شوند. در production، منبع فاقد ثبت مجوز مجاز نیست (AGENTS v4, R-154/R-155). ثبت در این فایل به معنی تأیید خودکار حقوقی نیست.

طبق ADR-024 (accepted, 2026-11-09): `license_note` متادیتای **ارجاع به شاهد** است و به‌تنهایی اثبات مجوز نیست. هر منبع باید منشأ قابل ردیابی، ناشر، سال چاپ و **شاهد مجوز واقعی** داشته باشد؛ اجازه باید صریحاً عملیات مدنظر (کسب، ذخیره، استخراج/OCR، embedding/ایندکس، نمایش/نقل) را پوشش دهد. مالک مسئول تأیید مجوزهای واقعی است. در حال حاضر **هیچ شاهد مجوز واقعی برای هیچ منبعی ثبت نشده است**؛ بنابراین فاز ۴ در گیت «ثبت و بازبینی مجوز منابع» باقی می‌ماند. هیچ رکورد مجوز ساختگی ایجاد نمی‌شود.
