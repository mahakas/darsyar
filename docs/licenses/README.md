# رجیستری مجوز منابع آموزشی

## گیت سخت

سیاست حاکم **strict** است (ADR-024). هیچ منبعی صرفاً به دلیل در دسترس بودن فایل یا شناخته‌شده بودن کتاب مجاز به ingestion تولیدی نیست. مجوز و منشأ باید برای هر منبع و هر عملیات مورد استفاده مستند و تأیید شوند.

برای هر منبع، رکورد رجیستری یا ارجاع دقیق در manifest باید حداقل این موارد را قابل بررسی کند:

- منشأ دقیق منبع و مبنای دسترسی/دریافت؛
- ناشر یا دارندهٔ حق و مشخصات نسخه، از جمله `edition_year`؛
- وضعیت و شواهد مجوز؛
- حدود مجاز ذخیره‌سازی، OCR/استخراج، embedding/نمایه‌سازی، نمایش/توزیع و نقل‌قول/اقتباس، هرکدام جداگانه در صورت کاربرد؛
- وضعیت بازبینی، مسئول تأیید و تاریخ ثبت تصمیم.

`license_note` در manifest اجباری است و باید به رکورد یا شواهد قابل بررسی ارجاع دهد. یادداشت کلی، خالی یا مبهم کافی نیست. فقدان یا ابهام به `failed` یا `needs_review` منجر می‌شود؛ سند در این وضعیت `ready` نیست و وارد ingestion تولیدی نمی‌شود.

ثبت یک مدرک در این رجیستری به‌تنهایی تأیید خودکار حقوقی ایجاد نمی‌کند. مجوز باید برای عملیات واقعی مورد استفاده تأیید شده باشد. فایل واقعی کتاب‌ها و محتوای دارای حق نشر را در Git commit نکن.
