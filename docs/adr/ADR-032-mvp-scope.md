# ADR-032: محدوده MVP

- Status: proposed
- Context: نسخه‌های قبلی دامنه‌های یادگیری بیشتری نام برده‌اند؛ نسخهٔ ۴ آن‌ها را برای جلوگیری از گسترش دامنه به تعویق می‌اندازد.
- Decision: MVP پایه‌های ۱ تا ۱۲، چت مستند، هویت، اعتبار/پرداخت، مدیریت و عملیات پایه است. آزمون‌ساز، پروفایل یادگیری خودکار و مشاورهٔ اختصاصی endpoint نمی‌گیرند.
- Rejected alternatives: افزودن همه قابلیت‌ها در نسخهٔ اول.
- Consequences: فاز ۸ فقط طرح آینده است؛ شروع آن نیازمند ADR جدید و تأیید مالک است.
- Affected files: `AGENTS.md`, `ROADMAP.md`, `docs/PRODUCT_SPEC.md`, `specs/phase-8.md`.
