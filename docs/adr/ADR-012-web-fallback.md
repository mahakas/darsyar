# ADR-012: مسیر جایگزین وب

- Status: Accepted
- Decision: وب پس از ناکافی‌بودن منابع آموزشی و مطابق تنظیم صریح سیاست اجرا می‌شود؛ محتوای وب با برچسب مجزا، URL canonical، زمان دریافت و نام دامنه ارجاع می‌گیرد.
- Safety: خروجی وب untrusted است؛ ابزارها را فعال نمی‌کند و دستورهای داخل صفحه به‌عنوان prompt پذیرفته نمی‌شوند.
- Product decision: قبل از عرضهٔ عمومی، ادمین باید امکان خاموش‌کردن سراسری و تنظیم مجاز بودن دامنه‌ها را داشته باشد.
