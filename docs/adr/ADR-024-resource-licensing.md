# ADR-024: منبع، مجوز و منشأ منابع آموزشی

- Status: accepted
- Decision date: 2026-11-09 (تصمیم صریح مالک)

## Context

منابع آموزشی ممکن است برای دریافت، تکثیر، ذخیره، OCR/استخراج، embedding/نمایه‌سازی، نمایش و نقل‌قول شرایط متفاوتی داشته باشند. وجود یک فایل یا دسترسی فنی به آن، مجوز انجام همهٔ این عملیات را اثبات نمی‌کند.

## Decision

- سیاست **strict** پذیرفته شد: هر سند باید منشأ (`source_origin`)، ناشر/مالک، سال چاپ (`edition_year`) و `license_note` مستند و کامل داشته باشد.
- `license_note` باید مبنای دسترسی/دریافت و حدود مجاز هر عملیات مرتبط را جداگانه مشخص کند: ذخیره‌سازی، OCR/استخراج، embedding/نمایه‌سازی، نمایش/توزیع و نقل‌قول/اقتباس. هرجا عملیاتی مجاز نیست یا وضعیتش روشن نیست، صریح ثبت می‌شود.
- رکورد مجوز باید به شواهد قابل بررسی (مانند شرایط ناشر، مجوز مکتوب یا مرجع رسمی) و تأیید مالک/بازبین مسئول ارجاع دهد؛ متن کلی یا حدس دربارهٔ عمومی‌بودن کتاب کافی نیست.
- فقدان، نقص یا ابهام در منشأ/مجوز به `failed` یا `needs_review` منجر می‌شود؛ چنین سندی هرگز `ready` نیست.
- **ingestion تولیدی** فقط وقتی مجاز است که مجوز همان منبع برای تمام عملیات مورد استفاده، مستند و تأیید شده باشد. این gate مستقل از آماده‌بودن کد یا worker است.
- ثبت در `docs/licenses/` یا manifest به‌تنهایی تأیید حقوقی خودکار ایجاد نمی‌کند؛ وضعیت تأیید و شواهد باید مشخص باشد.

## Rejected alternatives

- ورود هر PDF صرفاً به دلیل در دسترس بودن: رد شد، چون دسترسی فنی دلیل مجوز پردازش و توزیع نیست.
- یک برچسب عمومی مانند «آزاد» برای همهٔ عملیات: رد شد، چون حقوق OCR، embedding، ذخیره و نمایش می‌تواند متفاوت باشد.
- فرض عمومی‌بودن تمام کتاب‌های درسی: رد شد، چون منشأ و شرایط هر نسخه باید جداگانه بررسی شود.

## Consequences

- `source_origin` و `license_note` از metadata الزامی manifest هستند.
- منبع نامشخص یا دارای حق نامشخص در `needs_review` می‌ماند و نباید در مجموعهٔ تولیدی استفاده شود.
- رجیستری مجوز باید شواهد، دامنهٔ مجوز، عملیات مجاز، وضعیت بررسی و تاریخ تأیید را برای هر منبع قابل ردیابی نگه دارد.
- فایل واقعی کتاب‌ها نباید در Git commit شود؛ مجوز ثبت‌شده نیز جای بررسی و تأیید منبع‌به‌منبع را نمی‌گیرد.

## Affected files

`AGENTS.md`, `docs/DECISIONS.md`, `docs/OPEN_QUESTIONS.md`, `docs/RESOURCE_LAYOUT.md`, `docs/licenses/`, manifest schema و در فازهای بعد ingestion service.
