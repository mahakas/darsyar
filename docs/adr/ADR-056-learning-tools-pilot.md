# ADR-056: ابزارهای یادگیری وب، با پایلوت مرور دستی

- وضعیت: accepted برای **دامنه و ترتیب کار پس از MVP و منطق مستقل مرور**؛ نه مجوز انتشار یا پذیرش فازهای ۴ تا ۷.
- تاریخ: ۲۰۲۶-۱۱-۲۰. مبنا: درخواست مالک برای اجرای مرحله‌ای پیشنهادهای مقایسه با DeepTutor.
- مراجع: [فاز ۸](../../specs/phase-8.md)، [مرز MVP](ADR-032-mvp-scope.md)، [زیرساخت مجوز و حسابرسی](ADR-055-admin-authz-audit-foundation.md).

نوع ابزار را توسعه‌دهنده اضافه می‌کند؛ مدیر آن را پیکربندی و منتشر می‌کند. کاربر فقط عمل آموزشی انجام می‌دهد. اولین برش یک بستهٔ دستی است: نداشتن مدل یا اعتبار نباید مرور را متوقف کند. زمان‌بندی مرور تابعی قطعی از روز محلی مرور، فاصلهٔ قبلی و ارزیابی خود دانش‌آموز است؛ به مدل و تاریخچهٔ سایر کاربران نیاز ندارد. این سیاست آغازین قابل آزمون است، نه مدل علمی سنجش تسلط. برای مرورهای آینده نسخهٔ سیاست باید همراه رخداد ثبت شود.

گزینه‌های کنارگذاشته‌شده: تولید همهٔ کارت‌ها در لحظه (هزینه و دشواری اصلاح)، معماری افزونهٔ قابل نصب توسط کاربر (دور زدن کنترل مدیر)، اجرای یک‌جای پنج ابزار (وابستگی به منبع و دادهٔ تأییدنشده). از الگوی محصول DeepTutor الهام می‌گیریم؛ وابستگی اجرایی یا انتقال داده به آن نداریم.

تا احراز دروازه‌های سند فاز، این تصمیم فقط به طراحی و منطق مستقل و تست آن اجازه می‌دهد. هیچ route، جدول، seed، اقدام UI یا هزینهٔ جدیدی در MVP فعال نمی‌شود. این تصمیم محدودیت R-022 یا تصمیم‌های باز امنیت، retention و مجوز منبع را لغو نمی‌کند.
