# ADR-009: نسخه‌بندی وابستگی‌ها

- Status: Accepted
- Decision: نسخه‌ها به بازه‌های سازگار محدود می‌شوند و lockfile برای نصب تکرارپذیر در مخزن ثبت می‌شود. imageهای production باید با digest pin شوند.
- Patch security updates با CI و test suite سریع پیگیری می‌شوند؛ تغییر major یا تغییر معماری نیازمند ثبت ADR است.
- نسخهٔ انتخابی باید واقعاً نصب، build و test شود؛ اعلام نسخه بدون اجرای آزمون، تأیید سازگاری محسوب نمی‌شود.
