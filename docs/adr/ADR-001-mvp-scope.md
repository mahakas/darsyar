# ADR-001: محدودهٔ نسخهٔ اول

- Status: Accepted
- Decision: MVP روی دانش‌آموزان پایهٔ ۱ تا ۱۲ و منابع رسمی درسی متمرکز است. دانشگاه، اپ موبایل، voice کامل و قیمت‌گذاری مبتنی بر توکن خارج از نسخهٔ نخست‌اند.
- Reason: کاهش ریسک دامنه و امکان ارزیابی علمی.
- Consequences: مدل داده باید edition، publisher، grade و provenance داشته باشد؛ گسترش دانشگاهی بعداً با taxonomy مستقل انجام می‌شود.
- Open items: مالک قبل از عرضه عمومی نسخه/سال چاپ کتاب‌ها و حقوق پردازش را تأیید کند.
