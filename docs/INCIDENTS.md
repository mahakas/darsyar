# دفتر رخدادهای عملیاتی و امنیتی

این فایل الگوی ثبت رخداد است؛ در بسته رخداد واقعی ثبت نشده است.

## قالب رخداد
- ID:
- زمان شروع/پایان (UTC):
- شدت و دامنه:
- سرویس‌ها/کاربران متأثر:
- اثر روی داده/پول/حریم خصوصی:
- timeline و شواهد:
- ریشهٔ محتمل/تأییدشده:
- مهار فوری:
- اصلاح پایدار:
- بازیابی/تطبیق مالی:
- درس‌آموخته و اقدام دارای issue:
- تأیید مالک:

رکورد مالی برای پنهان‌کردن رخداد حذف یا ویرایش نمی‌شود. اسرار، OTP، token و متن خصوصی دانش‌آموز در این فایل قرار نمی‌گیرند.
